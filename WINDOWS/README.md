# OpenIntuneBaseline - Windows

Full documentation is available at **[docs.openintunebaseline.com](https://docs.openintunebaseline.com/platforms/windows/)**.

The baseline has been designed for, and tested on, Windows 11 Enterprise , Autopilot-enrolled, Microsoft Entra Joined, single-user devices with a standard user account.

> [!IMPORTANT]
> The Windows OIB has **not** been designed for hybrid-joined devices, and will likely **not work as expected or intended** on them. Successful application of the baseline outside of its intended configuration cannot be guaranteed.
